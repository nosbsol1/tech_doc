# Web技術 入門資料

## この資料について
新人エンジニアなど、Web開発をこれから始める人に向けて「Webシステムがどのような仕組みで動いているか」を説明する資料です。  
特定の言語やフレームワークの使い方ではなく、どの技術を使う場合にも共通する基礎（サーバー、HTTP、HTML、Cookie・セッションなど）を扱います。  

前提知識は特に必要ありません。プログラミングの経験（変数・関数が分かる程度）があると、コード例が読みやすくなります。
